Streamlit Cloud Secrets 입력 예시

GitHub에는 실제 DB 비밀번호를 올리지 마세요.
Streamlit Cloud 앱 생성 후 아래 위치에 직접 입력합니다.

App > Settings > Secrets

아래 형식으로 입력:

DATABASE_URL = "postgresql://postgres.xxxxxx:YOUR_PASSWORD@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres"

Supabase에서 Connection string을 복사한 뒤,
YOUR_PASSWORD 부분을 실제 DB 비밀번호로 바꿔 입력하면 됩니다.
